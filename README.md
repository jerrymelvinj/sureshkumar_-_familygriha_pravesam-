## ✨ Features

- **Architectural Watercolor Aesthetics:** Inspired by modern warm architectural sketches with saffron, marigold, terracotta, and sandalwood watercolor washes.
- **Interactive Geolocation & Navigation:**
  - Embedded live interactive map centered on Pennagaram / Dharmapuri.
  - One-tap turn-by-turn navigation via **Google Maps** and **Apple Maps**.
  - One-click **Copy Complete Address** with clipboard notification.
  - Travel route guide and distances from Dharmapuri (~28 km), Pennagaram bus stand (~3.5 km), Salem (~88 km), and Bengaluru (~145 km).
- **Direct Host Helpline:** Click-to-call and WhatsApp chat links for hosts and route coordinators.
- **Live Real-time Countdown:** Ticker counting down to Sunday, 22 November 2026, 8:30 AM IST.
- **Calendar Integration:** One-click Add to **Google Calendar** and download Apple / Outlook `.ics` calendar file.
- **Interactive Mobile Card Preview:** Dedicated modal showing the invitation as a sleek mobile digital card matching the reference mockup.
- **Interactive RSVP & Blessings Wall:** Guests can confirm attendance count and post blessings in real-time.
- **Devotional Ambient Melody:** Toggleable Indian classical flute & tanpura raga synthesized with standard Web Audio API.
- **WhatsApp Share:** Preformatted invitation text generator for easy sharing with family and friends.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation & Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Open in browser:
# http://localhost:5173/
```

### Production Build

```bash
npm run build
```
